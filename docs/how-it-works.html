How the briefing is produced, and how it stays reliable

A small, auditable pipeline. It reads only public sources, stores flat files in the Git repository, needs no servers or database, and costs close to nothing to run. Every source has several independent ways in, and every failure is surfaced.

Architecture

Runs twice daily (08:07 and 18:07 Dubai time) as a scheduled job

Reliability model

Several ways into every sourceRSS, the newsroom listing page, the sitemap and domain-restricted news search all run, and their results are merged. If one breaks, the others still deliver.
Independent second pathWAM and the Abu Dhabi Media Office republish most free-zone releases, so they are collected even if a zone's own site is down.
Three fetch tiersPlain HTTP with retries and backoff, then a headless browser, then a rendering reader proxy. A newsroom that loads but shows no article links is re-rendered before it counts as a failure.
Redesigns are detectedA page that loads but matches no article links is counted as a failure, so a site redesign raises an alert instead of going silent.
Self-healing stateURLs already seen are remembered. Failed article pages are retried on the next two runs, and a missed run is caught up automatically (up to 30 days).
AlertsAfter 2 consecutive failures, or when a newsroom is silent longer than its normal rhythm, a GitHub issue opens and the digest flags it. Both clear themselves on recovery.

Security, compliance and cost

Data handledPublic web content only. No personal data, no logins, no member data.
SecretsAPI key and SMTP details live in GitHub encrypted secrets. Nothing sensitive is stored in the repository.
Good-citizen crawlingRespects robots.txt paths, 1 request per second per site, and a small daily volume (a few hundred requests).
Third partiesGoogle/Bing News RSS (personal-use terms; use a licensed news API for wide internal distribution), Jina Reader as the last-resort fetch tier (can be switched off), and Claude (optional).
Running costHosting and scheduling: $0 (GitHub). Claude review: roughly $5–20 a month at current volumes; it is optional.
Hosting choicePublic GitHub Pages for the demo. For confidential use, move the same static folder behind SSO (Azure Static Web Apps or an internal web server) with no code changes.

Quality and testing

36 automated testsParsers, fetch fallbacks, baseline and retry logic, health alerts, a full end-to-end daily run, and real-URL regression samples captured from 23 live sites.
Live source checkA separate job tests every source against the real sites on each code change and every Monday, and fails if any source is completely down.
Analyst verificationItems marked verified were checked by hand against the source page: headline, date and key figures.

Known limitations and roadmap

Scheduler blockedGitHub Actions does not start jobs on the current account. The site is hosted without it, but daily automatic refresh needs Actions enabled or another scheduler (Azure Function, internal cron).
Hard sitesDAFZ and DIEZ block automated clients. They are covered through the browser tier, WAM and news search.
NextArabic-language sources, a Teams channel post, analyst feedback buttons to tune relevance, and deal-value extraction.
